## 📜 프로젝트 소개
방향키를 이용하여 생성되는 위험 구역을 피하며, 최대한 오래 살아남는 게임입니다.
## 🚀 기술 스택
HTML, CSS, JavaScript
## ❔ 주요 기능 및 플레이 방법
방향 키(상하좌우)를 이용하여 원을 움직일 수 있습니다.<br>
일정 시간마다 생성되는 특정 색상의 위험 구역이 생성되며, 닿으면 종료됩니다.<br>
이 구역들을 피해 최대한 오래 생존하세요!<br>
보드 크기, 원의 크기, 테마 등을 왼쪽에서 설정할 수 있습니다.<br>

## 😵 문제 해결과정
|문제|원인|해결과정|
|----|----|--------|
|원이 게임 판 밖으로 벗어남|위치를 감지하는 수식|`2*size/3+x` -> `size/3*2+x`로 수정(y 좌표도 동일)|
|위험 구역 생성 주기와 사라지는 시간이<br/>불규칙적|이미 생성된 구역에 중복 하여 생성|위험 구역 존재 여부를 확인
